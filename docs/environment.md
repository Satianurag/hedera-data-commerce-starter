# Environment index

Read [configuration and recovery](configuration.md) first. No variables are needed to start the read-only Next app. Next loads `packages/nextjs/.env.local`; Go commands and root tools read only their process environment. Export each process's settings separately. Never copy test-fixture controls into a deployment.

“Required” means required for the selected feature or command. Feature switches default to disabled and accept the literal `true` to enable them. Invalid configuration returns an error or disables the affected route. Use numeric Hedera IDs (`0.0.<number>`) and owner-only private files outside the checkout: file mode `0600`, directory mode `0700`.

| Variable                                                     | Default / format                                                   | Purpose and failure behavior                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HEDERA_NETWORK`                                             | App reads: `testnet`; server write commands: required explicitly   | `testnet` or read-only `mainnet`. Auth and payment adapters require explicit `testnet`; setting only the CLI network does not set this variable.                                                                                                                                  |
| `HEDERA_CHAIN_ID`                                            | Derived: `296` testnet, `295` mainnet                              | Optional consistency assertion; mismatch rejects configuration.                                                                                                                                                                                                                   |
| `HEDERA_MIRROR_URL`                                          | Official HTTPS Mirror origin for selected network                  | Optional assertion; alternate origins or network mismatch rejected.                                                                                                                                                                                                               |
| `NEURON_LEGACY_DIRECTORY_URL`                                | Canonical Neuron testnet directory; none on mainnet                | Alternate directories rejected; owned sellers use direct discovery below.                                                                                                                                                                                                         |
| `HEDERA_RPC_URL`                                             | Funding: unset; native deployment: `https://testnet.hashio.io/api` | Funding requires an explicit HTTPS JSON-RPC URL. Native deployment uses the default testnet relay unless overridden. Chain preflight must match. The mainnet read configuration rejects Hashio/local/IP hosts. The reference adapter has its own JSON `rpcUrl`, not this setting. |
| `NEURON_ENABLE_CUSTOMER_AUTH`                                | `false`                                                            | Enables testnet wallet authentication; missing origin/private DB configuration fails.                                                                                                                                                                                             |
| `NEURON_APP_ORIGIN`                                          | Required for auth, gateway and loopback direct discovery           | Exact HTTPS origin or explicit-port loopback HTTP origin; no trailing slash. Origin/Host mismatch rejects writes. `localhost` and `127.0.0.1` are distinct.                                                                                                                       |
| `NEURON_CUSTOMER_DB_FILE`                                    | Required for auth                                                  | Absolute SQLite file in an existing owner-only directory. Unsafe ownership, permissions or symlinks rejected. Preserve DB/WAL/SHM during recovery.                                                                                                                                |
| `NEURON_ALLOWED_CUSTOMER_ADDRESSES`                          | Unset; required for HTTPS auth                                     | 1–20 comma-separated checksummed EVM addresses, no spaces. Invalid/missing allowlist denies public access. Loopback access is not restricted by this list.                                                                                                                        |
| `NEURON_REOWN_PROJECT_ID`                                    | Unset                                                              | Optional 32-hex project ID for WalletConnect. Missing/invalid ID disables WalletConnect. Injected wallets do not need it.                                                                                                                                                         |
| `NEURON_ENABLE_REFERENCE_COMMERCE`                           | `false`                                                            | Enables authenticated reference commerce only with configured bridge and auth.                                                                                                                                                                                                    |
| `NEURON_ENABLE_LOCAL_STREAM` / `NEURON_ENABLE_REMOTE_STREAM` | Both `false`                                                       | Enables local WS or public WSS gateway access; configure exactly the intended path, network, customer binding and endpoint.                                                                                                                                                       |
| `NEURON_ENABLE_CUSTOMER_REQUEST`                             | `false`                                                            | Enables HCS data request only with auth, stream and request configuration.                                                                                                                                                                                                        |
| `NEURON_ENABLE_PUBLIC_CUSTOMER_REQUEST`                      | `false`                                                            | Additional HTTPS request gate; also requires remote stream and lifetime request limit.                                                                                                                                                                                            |
| `NEURON_ENABLE_CUSTOMER_COMMERCE_REVIEW`                     | `false`                                                            | Enables seller-signed native quote review. Missing exact identities/limits rejected.                                                                                                                                                                                              |
| `NEURON_ENABLE_CUSTOMER_FUNDING`                             | `false`                                                            | New funding also requires review, auth and approval configuration. Disabling new funding does not erase existing recovery history.                                                                                                                                                |
| `NEURON_ENABLE_CUSTOMER_APPROVAL`                            | `false`                                                            | Enables approval after confirmed request and completed same-session positive-byte delivery. It does not automatically approve payment.                                                                                                                                            |

## Gateway, discovery and request process

These settings are shared by the relevant Next/Go processes as described in [stream setup](configuration.md#legacy-streaming) and [owned seller setup](native-seller.md). Ports shown as examples are **not defaults** unless explicitly stated.

| Variable                                                  | Default / format                                             | Purpose and failure behavior                                                                                                                                                            |
| --------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NEURON_SELLER_DISCOVERY`                                 | `canonical`                                                  | `canonical` or `direct`; invalid modes are rejected. No automatic fallback.                                                                                                             |
| `NEURON_DIRECT_SELLER_PROFILE_FILE`                       | Required in direct mode                                      | Absolute owner-only JSON profile and parent. Mirror key/topics must match the selected seller; loopback profiles also require local origin/WS configuration.                            |
| `NEURON_SELLER_ACCOUNT_ID`                                | Required                                                     | Selected account, same across gateway/request/approval and any direct profile.                                                                                                          |
| `NEURON_SELLER_STDIN_TOPIC_ID`                            | Required for requests                                        | Seller inbox topic; active/open and bound to selection. Wrong topic blocks request/approval.                                                                                            |
| `HEDERA_BUYER_ACCOUNT_ID` / `HEDERA_BUYER_STDIN_TOPIC_ID` | Required for requests                                        | Buyer account and open reply topic. Both checked against testnet.                                                                                                                       |
| `HEDERA_SHARED_ACCOUNT_ID`                                | Required for requests                                        | Legacy shared account; the direct seller setup requires a balance below 100 tinybar.                                                                                                    |
| `HEDERA_BUYER_KEY_FILE`                                   | Required for gateway/request                                 | Owner-only secp256k1 DER-hex key file. Raw32 quote-key files are not interchangeable; invalid format fails before protocol startup.                                                     |
| `NEURON_UDP_PORT`                                         | Required, integer `1`–`65535`                                | Gateway QUIC listener (example `4001`); missing/zero/invalid fails.                                                                                                                     |
| `NEURON_GATEWAY_LISTEN`                                   | Required `host:port`                                         | Example `127.0.0.1:9080`. Non-loopback requires TLS, journal and customer-session checks.                                                                                               |
| `NEURON_TLS_CERT_FILE` / `NEURON_TLS_KEY_FILE`            | Unset for loopback HTTP; both required for public listener   | PEM certificate/private-key files for gateway-owned TLS. Invalid pair prevents TLS startup. The documented nginx deployment instead terminates TLS in nginx and keeps gateway loopback. |
| `NEURON_GATEWAY_WS_URL`                                   | Required for streaming                                       | Local explicit-port `ws://.../stream`, or `wss://<public-host>/stream` without a custom port. Invalid endpoint denies tickets.                                                          |
| `NEURON_GATEWAY_PUBLIC_HOST`                              | Required for remote stream                                   | Exact public hostname matching WSS endpoint. Mismatch denies ticket/request/approval.                                                                                                   |
| `NEURON_GATEWAY_INTERNAL_ORIGIN`                          | Required for remote server checks                            | Loopback origin used by Next for gateway health/session checks; not exposed as browser endpoint.                                                                                        |
| `NEURON_GATEWAY_SESSION_CHECK_URL`                        | Unset; required for public listener/customer-bound streaming | Exact app loopback `/api/gateway-session` endpoint (example `http://127.0.0.1:3000/api/gateway-session`). Missing public binding refuses startup.                                       |
| `NEURON_SESSION_TOKEN_FILE`                               | Required for stream                                          | Shared owner-only file containing 64 hex characters (32 random bytes). Missing/unsafe/invalid file rejects HMAC ticket creation/verification.                                           |
| `NEURON_SESSION_JOURNAL_FILE`                             | Optional local; required non-loopback                        | Private durable journal; invalid/locked journal blocks startup. Retain it across restarts.                                                                                              |
| `NEURON_PUBLIC_UDP_MULTIADDR`                             | Required for request                                         | Selected literal-IPv4 `/ip4/.../udp/.../quic-v1` address; routability must match public/loopback profile policy. Invalid address rejected before submission.                            |
| `NEURON_LEGACY_REQUEST_BIN` / `NEURON_HCS_SUBMIT_BIN`     | Required for app request                                     | Absolute executable paths with owner-only immediate parent; untrusted executable/parent rejected.                                                                                       |
| `NEURON_PUBLIC_REQUEST_LIMIT`                             | Required for HTTPS request; integer `1`–`100`                | Lifetime count for the database, not a resettable rate limit. Exhaustion refuses new requests; do not erase the database.                                                               |
| `NEURON_NATIVE_SELLER_CONFIG_FILE`                        | Required for `cmd/native-seller`                             | Owner-only JSON configuration; schema/identity/escrow/request checks precede file replay.                                                                                               |
| `NEURON_NATIVE_QUOTE_CONFIG_FILE`                         | Required for `native:quote`                                  | Owner-only JSON config; includes raw32 seller key path, terms and authenticated buyer descriptor. Invalid/stale terms rejected.                                                         |

## Native commerce, HCS and deployment

| Variable                                                               | Default / format                             | Purpose and failure behavior                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `NEURON_COMMERCE_SELLER_ACCOUNT_ID` / `NEURON_COMMERCE_QUOTE_TOPIC_ID` | Required for review                          | Exact seller and signed-quote topic. When approving delivery, seller must also match the gateway/request seller.                                                                                                                                                                                             |
| `NEURON_COMMERCE_SERVICE_ID`                                           | Required, 1–128 characters `[A-Za-z0-9._:-]` | Service bound into quote; current delivery approval supports `1` (ADS-B) only.                                                                                                                                                                                                                               |
| `NEURON_COMMERCE_MAX_SPEND_TINYBAR`                                    | Required positive integer, ≤100,000,000      | Principal cap (1 HBAR); excess or missing configuration rejects review.                                                                                                                                                                                                                                      |
| `NEURON_COMMERCE_MAX_TX_FEE_TINYBAR`                                   | Required positive integer, ≤100,000,000      | Buyer per-transaction fee cap; gas/fee/balance checked before wallet opening.                                                                                                                                                                                                                                |
| `NEURON_ESCROW_RUNTIME_SHA256`                                         | Required lowercase 64-hex                    | SHA-256 of deployed runtime bytecode. Mismatch blocks funding/recovery authorization.                                                                                                                                                                                                                        |
| `HEDERA_CONTRACT_ID` / `HEDERA_CONTRACT_ADDRESS`                       | Required for commerce/contract verifier      | Exact selected numeric ID and nonzero checksummed EVM address; chain metadata/runtime must agree.                                                                                                                                                                                                            |
| `HEDERA_OPERATOR_ACCOUNT_ID`                                           | Required for HCS/request/setup/deploy        | Fee payer/signer account. Independently checked against key and topic/network policy.                                                                                                                                                                                                                        |
| `HEDERA_OPERATOR_KEY_FILE`                                             | Required for those commands                  | Private DER-hex key; HCS accepts the configured topic's supported key type, native deploy requires secp256k1. See [key formats](native-seller.md#key-formats).                                                                                                                                               |
| `HEDERA_MAX_FEE_TINYBAR`                                               | Required positive integer                    | HCS writer per-operation budget divided among chunks; SDK retries mean no hard aggregate-spend guarantee. App request and native deploy impose their own ≤1 HBAR cap; the funded verifier compares a fixed 400,000 gas limit × observed gas price with this budget, not a transaction-specific gas estimate. |
| `HEDERA_TOPIC_ID`                                                      | Required for `hcs:submit`                    | Target topic checked on selected network before writing.                                                                                                                                                                                                                                                     |
| `HEDERA_TOPIC_ACCESS`                                                  | `controlled`                                 | Explicit `open` required for open topic; controlled submit-key must match operator. Custom-fee topics rejected.                                                                                                                                                                                              |
| `HEDERA_ALLOW_MAINNET_WRITES`                                          | `false`                                      | Standalone HCS writer only: `true` permits mainnet submission when that network is selected. Does not enable app/commerce mainnet support.                                                                                                                                                                   |
| `HEDERA_CONTRACT_GAS`                                                  | Required deployment gas budget               | Positive integer ≤2,000,000. Invalid bounds or gas price × limit above the fee cap abort before submission. Choose sufficient gas: the script does not estimate it, and insufficient gas can fail on-chain and consume fees.                                                                                 |
| `HEDERA_DEPLOYMENT_JOURNAL_FILE`                                       | Required absolute private path               | Durable signed deployment intent and companion SQLite lock. Unsafe path/configuration mismatch rejected. Resume same journal after uncertain outcome; never publish it.                                                                                                                                      |

## Optional test and scaffold controls

The funded contract verifier (`npm run test:live -w @neuron/foundry`) uses the network, RPC, contract, buyer and fee variables above, plus the following. It spends testnet principal and fees; root `npm run test:live` is read-only.

| Variable                                              | Default / format                                      | Purpose and failure behavior                                                                                                                          |
| ----------------------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HEDERA_SELLER_ACCOUNT_ID` / `HEDERA_SELLER_KEY_FILE` | Required for funded Foundry `test:live`               | Separate seller account and private DER-hex secp256k1 key. Buyer uses `HEDERA_BUYER_ACCOUNT_ID` / `HEDERA_BUYER_KEY_FILE`; accounts must be distinct. |
| `HEDERA_TEST_JOURNAL_FILE`                            | Required absolute owner-only file for funded verifier | Appended transaction hashes for the contract test run; separate from the app recovery journal.                                                        |

All test controls belong in the test runner's environment, not app `.env.local`. See [verification](verification.md). Supply every value in a live HCS group or leave the whole group unset. Record expected bytes and hashes independently.

Native source repair also honors node-gyp’s `NODE_GYP_FORCE_PYTHON` when selecting an explicitly installed Python interpreter; an incompatible forced interpreter fails the build. The repair command downloads exact node-gyp 13.1.0 only when needed; `--force` explicitly rebuilds a healthy binding and preserves the prior prebuild and local build. A failed rebuild restores any prior local build; retained backups remain under the dependency directory, separate from customer state.

Framework/tool-internal variables are not app configuration: `CI` controls test retries/reporting; `NODE_ENV` selects framework behavior; `NODE_OPTIONS` is used for test-only fetch preloads; `PATH` locates prerequisites; `npm_execpath` locates the active package-manager executable; `GIT_CONFIG_COUNT` and numbered `GIT_CONFIG_KEY_*`/`GIT_CONFIG_VALUE_*` inject ephemeral Git identity for the isolated gate. `REFERENCE_JOURNAL_CHILD`, `REFERENCE_JOURNAL_DIR`, `TEST_JOURNAL` and `TEST_KEY` are disposable child-process test controls. Never set fixture preload variables in production. `NEURON_REFERENCE_BINARY` in the restart guide is an operator shell convenience naming the built executable, not an environment value read by application code.
